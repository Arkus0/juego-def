# WP-M0-00 — First Walking Street

Status: **READY / NEXT**  
Class: PRODUCT SLICE / FOUNDATION-TO-GAME TRANSITION  
Depends on: Bootstrap Unity + GC2 Core PASS  
Blocks: `WP-PROD-ASSET-00`, `WP-PROD-DIALOGUE-01`

## Claim

juego-def has its first retained, playable GC2 street: the player can walk through a short port-town route, understand the space, examine/use a world interaction and interact with one NPC in Play Mode.

M0 proves the direct production path `Unity + GC2 + bounded MCP operator` on a visible game fragment and establishes the **real gameplay scale/camera/interaction fixture that the graphical factories must target**. It does not itself build those factories.

## Required retained output

Create a new retained M0 scene or retained evolution of the bootstrap containing at minimum:

1. existing GC2 player + third-person camera, tuned to comfortable walking inspection;
2. one short, legible port-town street/route at believable pedestrian scale;
3. one door/hotspot or equivalent world interaction;
4. one examinable object with a visible/textual result;
5. one non-capsule NPC in the same route;
6. one real GC2 interaction with that NPC producing a brief visible response and, if practical, a simple gesture;
7. lighting/atmosphere coherent enough with the Visual Bible that the scene is useful as a factory target fixture.

## Environment scope

M0 is **not** the environment factory.

- primitive geometry may be used as explicitly temporary structural aid;
- primitive boxes may not be presented as keeper facades/buildings by attaching decorative assets;
- use real admitted assets/components where reasonably available;
- composition must care about player scale, route width, ground contact, entrance/readability and at least one port-town cue;
- unavailable art is marked `PROXY` instead of silently approved.

The purpose is to give `PROD-ASSET-00` and later ENV/CHAR/ANIM factories a truthful in-game target, not to solve their production breadth early.

## Operator execution loop

Use the adopted bounded operator:

`inspect -> plan bounded change -> build/wire -> Play Mode -> inspect console/runtime/capture -> correct real issue -> replay`

The correction should respond to actual evidence such as collision, scale, camera, reach, lighting, hierarchy, GC2 binding or route readability.

## Gameplay requirements

### Player/camera

- preserve working GC2 player/camera baseline;
- tune movement toward walking/exploration feel if needed;
- owner performs one keyboard/mouse feel check before PASS.

### World interaction

At least one real GC2-triggered/hotspot interaction with observable result.

### NPC

NPC may be non-final civilian art but cannot be a capsule/cube. Interaction is actual gameplay wiring; Dialogue module is not required.

## Evidence

Retain under `Docs/evidence/WP-M0-00/`:

- short result README;
- retained scene path;
- at least 3 captures: route/readability, world interaction, NPC encounter;
- Play Mode proof of movement + interactions;
- console status;
- owner hand-test note;
- operator failure/correction notes where useful;
- explicit `PROXY` inventory.

## PASS

PASS only when:

- retained M0 scene compiles/plays;
- owner can walk the route with GC2 player/camera;
- route is plausible/readable in third person;
- one world interaction works;
- one NPC interaction works;
- no blocking runtime issue remains;
- scene has at least one real port-town/Atlantic identity cue;
- proxies are explicit;
- no H0/H1 or unnecessary custom framework was introduced.

## FAIL / stop conditions

FAIL if success depends on uncaptured hand repair, GC2 baseline regresses, interaction is staged/faked, dressed greybox is claimed as keeper art, or work expands into building the future graphical factories inside M0.

## Non-goals

No Dialogue/Inventory/Quests/Behavior/Melee/Perception requirement. No final district. No final NPC art. No final environment kit. No full interior. No H1 lifecycle witness.

## Handoff

On PASS:

1. execute `WP-PROD-ASSET-00` to create the shared graphical asset substrate;
2. `WP-PROD-DIALOGUE-01` may begin in parallel using the M0 NPC fixture;
3. after ASSET-00, start ENV/CHAR/ANIM factories concurrently.
