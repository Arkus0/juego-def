# WP-PROD-CHAR-02 — Representative Population Batch

Status: **READY AFTER CHAR-01**  
Class: PRODUCTION FACTORY / POPULATION  
Depends on: `WP-PROD-CHAR-01` PASS  
Blocks: `WP-CITY-URBAN-01`

## Claim

The accepted character recipe scales beyond a four-character proof into a small but representative civilian batch suitable for populating the first keeper block without collapsing into clones or bespoke one-offs.

## Required output

Produce a representative batch of **8–12 ordinary civilians** using the accepted CHAR recipe.

The exact count is secondary to coverage. The batch should demonstrate useful variation across:

- silhouette/body presentation;
- age band where available;
- work/social role cues;
- palette/material variation;
- hair/head/accessories where supported;
- at least several combinations that are not simple recolours of the same outfit.

## Constraints

- reuse the accepted base/rig/wardrobe process;
- keep every character compatible with the accepted animation path;
- do not invent story biographies merely to justify visual variation;
- do not require bespoke mesh surgery for most variants;
- keep obvious fantasy/costume signals out unless transformed into a believable civilian use;
- keep performance/prefab complexity reasonable for several simultaneous NPCs.

## Representative town roles

Use the town context to guide coverage, for example:

- shop/bar worker;
- dock/warehouse worker;
- older resident;
- younger resident;
- office/service worker;
- casual/nightlife visitor;
- market worker/customer;
- neutral everyday pedestrian.

These are visual-production roles, not canonical narrative identities.

## Evidence

Retain under `Docs/evidence/WP-PROD-CHAR-02/`:

- group captures in gameplay lighting/camera;
- batch inventory with prefab path + source families;
- repeated setup notes;
- any combinations rejected for clipping/coherence;
- one scene containing several variants together to expose clone/coherence problems.

## PASS

PASS when:

- 8–12 usable civilians exist from the same recipe;
- group reads as one game's population rather than unrelated packs;
- no systemic clipping/rig/material blocker remains;
- variants can be instantiated and animated through the shared path;
- owner accepts the batch as sufficient population language for `CITY-URBAN-01`.

## FAIL

FAIL if population breadth is achieved by unrelated pipelines, obvious clones dominate, most variants need bespoke repair, or the group does not visually belong in the intended port town.

## Non-goals

No final 100-NPC population, named important cast, facial animation lock, crowd simulation or NPC routines.
