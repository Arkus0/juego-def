# ENV01 reuse map — vocabulary, never layout

Research lineage: ENV01 PR #10, commit
`246756c72d7181cd034c04c6b5cde163d076cb66`. Catalog/source files were inspected at
that commit; PR #10 is OPEN, so this is a **tooling/research inventory**, not an
independent acceptance claim. No generated 311-body layout or random facade program
is imported into Potes authority.

| Family / exact existing component examples | Disposition | Reference-driven use / constraint |
| --- | --- | --- |
| `ENV_Plaster_Lime`, `ENV_Plaster_Sandstone`, `ENV_Plaster_PaleOchre`, `ENV_Joinery_Chestnut` | REUSE_EXACT as material candidates | Keep source/owned material lineage; color/condition ultimately follows documented facade. No blanket palette applied to unknown walls. |
| `ENV_Wall_Plaster_Clean*`, clean stone wall vocabulary | RECOMPOSE | Donor surfaces for true footprint/face planes. Never snap, resize or regularize a whole building to 2 m bays. |
| `ENV_Window_Insert_Wide*`, `ENV_Window_Insert_Thin`, `ENV_Window_Wide_Ashlar`, `ENV_Window_Reja` | ADAPT | Match measured/reference opening shape, size and centre; exact opening count controls assembly. Need more varied narrow glazing and surrounds. |
| `ENV_Door_Portal_Reformed`, `ENV_Door_Service`, `ENV_Shopfront_Door`, `ENV_Door_Balcony` | ADAPT | Match actual observed timber/glass doors. Do not create an extra service/portal entrance to satisfy threshold grammar. |
| `ENV_Gallery_Bay`, `ENV_Solana_Bay`, `ENV_Solana_Wing` | RECOMPOSE / ADAPT | Preserve full gallery/solana length, returns and floor position. B042 and narrow commercial galleries require compound assemblies. |
| `ENV_Roof_Gable_4/6/8`, native round-tile roof pieces | ADAPT | Tile/eave donors only; trace actual compound roof plan, ridge/hip/valley graph and height. No automatic gabled rectangle substitution. |
| Hipped roofs, compound roof valleys, irregular wedge/return shells, exact deep tile canopy | MISSING | New bounded derivatives after source facts resolve; neither source kit nor generator may decide topology. |
| `ENV_Retaining_Wall_2x1/2x2/2x3`, `ENV_Quay_Wall_4m` | ADAPT | Material/coping donors for exact surveyed/photographed river and parcel walls. No invented straight 9 m channel. |
| `ENV_Bridge_Arch`, `ENV_River_Stairs` | ADAPT | Geometry/scale/profiles must follow San Cayetano and road-bridge reference. Existing arch is not a measured bridge. Deck/crest control missing. |
| Street paving/canto/flag material families | REUSE_EXACT / RECOMPOSE | Use documented surfaces and exact street/step levels. Existing 70/20/10 authored slope policy is **NOT_NEEDED** for this replica. |
| Stone surrounds, canecillos, joinery, balcony guards, downpipes | ADAPT | Match visible proportions and attachments individually; no probabilistic history pass on referenced facade. |
| Structural trees / ivy | ADAPT when documented | Fixed vegetation requires geolocated identity/extent. Do not seed a generic garden in an evidence gap. |
| Bins, cafe chairs/tables, pots, temporary awnings | REUSE_EXACT for later transient dressing | Only after structural reference; cannot obstruct or redefine thresholds/routes. Not forensic replicas of every movable object. |
| Procedural `EnvDistrict`, `FacadeGrammar`, `EnvCharacter`, business/floor randomization | NOT_NEEDED as spatial/facade authority | The recorded footprint, opening and roof facts own exterior composition. Useful low-level asset discovery/validation may be isolated later. |
| Interiors, Quay/port programming, mission/NPC assignment, generated ENV01 building units | NOT_NEEDED | Outside this WP. No preservation of a complete generated house due to sunk cost. |
