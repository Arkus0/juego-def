## Validation boundary

`python Tools/asset_catalog.py validate` verifies source existence/digests, archive identity, license pointers, unique IDs, installed paths/GUIDs and owned derivative lineage. `Tools/JuegoDef/Validate Asset Intake` in Unity checks imported model scale, Humanoid avatars, prefab materials/scripts and unresolved serialized GUIDs. These checks flag common technical failures; human and lane-specific review still decide visual fit and animation quality. The validator output is retained in `VALIDATION.json` and [Unity validation](UNITY_VALIDATION.md). The Unity run found one missing texture GUID in the vendor `MI_Plaster.mat`; it is recorded as an ENV material gap.
